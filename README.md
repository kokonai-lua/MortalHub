# MortalHub# Panda | Mortal

A Roblox script hub by **Panda**.

## Usage

Paste this into your executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/kokonai-lua/MortalHub/refs/heads/main/TRYING_OUT_panda_v10.lua"))()
```

## Features

- Custom user tags
- Whitelist support
- Live user list

## Backend

This script uses [Supabase](https://supabase.com) for its whitelist, tags and live user list.
Only the **publishable** key belongs in the script. Never commit your secret or `service_role` key.
